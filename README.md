## How it works

`main.ts` (Node 22, standard library only) copies the poster `entry.png`
(1024×1024 PNG) to the output directory. It reads no network, no clock and
no other input, so every run writes the same bytes.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Files

- `main.ts` — the entry program
- `entry.png` — the poster (1024×1024)
- `SOURCES.md` — each of the six stories with its sources
- `METHODOLOGY.md` — how the six stories were chosen and verified
- `LICENSE` — MIT
